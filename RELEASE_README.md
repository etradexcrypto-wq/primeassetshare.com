# primeassetshare.com — Frontend Release

This archive contains the completed dark-only primeassetshare.com investment frontend.

## Included

- React + Vite frontend source in `client/`
- Responsive homepage, Market, Approach, About, Contact, and Insights pages
- Premium animated preloader and dark blue/black/silver visual system
- Public CDN image and video references
- Live market ticker and market research interface
- Four investment plan cards
- Four branded certificate cards with browser PDF downloads
- Social metadata, favicon, and `manifest.webmanifest`
- Production build in `dist/`

## Run locally

```bash
pnpm install
pnpm dev
```

## Validate and build

```bash
pnpm check
pnpm build
```

The site is frontend-only. Account CTAs link to `https://app.primeassetshare.com`.
